# FVI小样本标注与模型映射

沿用“素材与抽帧→标注工作台→训练数据集→模型训练→模型仓库”。多选图片或文件夹批量追加，原图只导入一次，再选检测/实例/语义的独立标注集；不要为三个任务复制三份原始视频。原图与外部标注导入均按内容身份校验，明确拆分不能含相同原图。

先定义对象角色，再定义类别。同一类别可以有多个实例：两块Tray画两个独立框，两条绑带画两条，双手各画一只。C类数量来自全部合格实例，与A类最高置信动作不同。框应贴合可辨认的可见目标，细长绑带不能用整盘Tray大框替代；实例分割才使用精确多边形。检测框不是精确mask。

“正/侧”可能是同一物体的姿态，也可能是不同物体（竖板与平放Tray）。在标注规范中逐项声明；规则里仅对明确同一作业对象、范围内唯一候选的姿态启用替代。不能全局合并两个类别。多人手、多个盘、互相遮挡和背景上的绑带都须进入样本，防止模型把场景整体背下来。

遮挡不猜不可见边界；难辨图排除首轮或标记待复核。语义任务区分背景/未标注/忽略，不能把不确定像素涂成背景；本轮不修复旧语义忽略值审核问题A24-003，不将相关数据链宣称已验收。实例多片段原始数据可保存；选定YOLO格式无法表达时导出明确拒绝，不静默拆成多个实例。保留正负样本：正常两绑带、缺一根、全无、手遮挡、空区、多盘归属不清、金属环/印章/工单相邻混淆。

按原视频/拍摄片段划分train/val/test，避免相邻近重复帧随机散布；查看划分预览，明确已有拆分，来源不足时先确认风险。测试集不调参。本轮复用已有小样本，缺真实FVI动作与姿态样本时记录待验，不批量造样或反复重训。

选择数据集任务后再选Pie型号；标签显示名不等于权重已支持该标签。导出包后，在Web绑定模型并选择实际来源/标签，发布校验会核对任务和标签映射。新C标签未训练进模型时应报错，不能仅改页面名称就认为模型有了能力。
